# Peaker height data

Offline country packs for the [Peaker](https://github.com/mowolf/peaker) iOS app: elevation tiles and peak
databases, served as static files straight from this repository:

```
https://raw.githubusercontent.com/mowolf/height-data/main/v1/catalog.json
```

| path | what |
|---|---|
| `v1/catalog.json` | all countries, sizes, land-tile bitset, attribution |
| `v1/countries/<CC>.json` | one pack: its tiles (size + SHA-256) and peak database |
| `v1/tiles/90/<tile>.pkt` | 90 m elevation tiles (Copernicus GLO-90), used for the far view |
| `v1/tiles/30/<tile>.pkt` | 30 m elevation tiles (Copernicus GLO-30), used near the viewer |
| `v1/peaks/<CC>.<build>.sqlite.deflate` | peak database (SQLite, raw DEFLATE) |

Formats: [tile format](https://github.com/mowolf/peaker/blob/master/docs/tile-format.md),
[pack format](https://github.com/mowolf/peaker/blob/master/docs/pack-format.md). Everything here is generated by
the pipeline in the Peaker repo (`peaker-pipeline pack` + `peaker-pipeline publish --repo …`); don't edit by hand.

Countries: Nepal (incl. 50 km into Tibet and India).
